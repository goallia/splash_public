## What's in this repo

| Folder | What it's for |
|---|---|
| [`specs/`](specs/) | Product specs (PRDs) — template plus an example |
| [`decisions/`](decisions/) | Decision log — why we decided what we decided |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Forms for feature requests and bug reports |
| [`project-board/`](project-board/) | How to set up the Product Roadmap board |

## Quick start

- **New idea or bug?** Open an [issue](https://github.com/goallia/splash_public/issues/new/choose) and pick a template.
- **Writing a spec?** Copy [`specs/_TEMPLATE.md`](specs/_TEMPLATE.md).
- **Made a decision?** Record it with [`decisions/_TEMPLATE.md`](decisions/_TEMPLATE.md).
