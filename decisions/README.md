# Decision log

Short records of important product decisions and **why** we made them, so future team members can follow the reasoning.

## How to add a decision

1. Copy [`_TEMPLATE.md`](_TEMPLATE.md) to `decisions/NNNN-short-title.md`, using the next number.
2. Fill it in and open a pull request.
3. Add it to the index below.

Never delete old decisions. If one changes, write a new record and set the old one's status to `Superseded by NNNN`.
