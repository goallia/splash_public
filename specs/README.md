# Specs

Product specs (PRDs) live here as Markdown files.

## How to write a new spec

1. Copy [`_TEMPLATE.md`](_TEMPLATE.md) to a new file, e.g. `specs/my-feature.md`.
2. Fill it in on a new branch and open a **pull request**.
3. Reviewers comment directly on the lines they have questions about.
4. Once approved, set **Status** to `Approved` and merge.

See [`example-match-notifications.md`](example-match-notifications.md) for a filled-in example.
